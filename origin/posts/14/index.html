『树上的X爵』

2026.11.21 约 2600 字 预计阅读 5 分钟 次阅读

我和 X 坐在应元楼旁的一棵树下，看着中心广场上稀稀落落的人们走得匆匆，正值周末放学的中午。

我：“来说点比较有文艺风的句子吧。”

X：“我觉得你这句就挺有的。”

我：“过奖过奖。”

X：“让我也想想，我或许会从一个荒诞的角度入手，比如突然开始扯原神之类的。”

我：“诶你不觉得原神跑图真的很舒适吗？”

X：“你的学习能力太强了。”

我：“过奖过奖。”

X：“唉，转眼就放学了。”

我：“每周都会迎来放学的日子。一件事情被重复上千次，居然不会感到无聊，除了基础的生理需求之外，可能只有放学这件事能做到了。”

X：“你这样说，那放学确实是一件很神奇的事情。”

我：“是因为我说了它才成为了有趣的事情吗？”

X：“嗯，是的。”

像这样的对话，在我们之间还有很多。X 实在是一个很神秘的人，我喜欢神秘的人，于是我们总是稀里糊涂地就坐在这里开始聊天了。

但是今天，我注意到了 X 的眼里有着与平常不一样的神情。

X：“这个世界还是很多姿多彩的。”

我：“怎么证明？”

X：“比如那边那个倒吊在树上的人。”

倒吊在树上的人。

¿

我：“我去，居然有人倒吊在树上。”

X：“这么显眼你都没看到。”

我：“走，过去看看。”

我们走了过去。走路是一个距离逐渐拉近的过程，在这个过程中是很尴尬的。比如那人虽然一直在倒吊着，双腿夹着一个粗树枝，但眼睛炯炯有神，始终死死地盯着我们两人。就这样慢慢走近后，我说：

“同学啊……高三确实是压力很大的时期……”

ㄚ：“停。”

（“ㄚ”指的是倒悬的“人”，嗯这可能是一个强行的、失败的象形梗）

ㄚ：“我知道你要说什么，你要说‘为什么你倒吊在树上’。”

我：“我觉得这不难猜到，所以为什么。”

ㄚ：“其实上来就问别人为什么做一件并没有影响到他人的事，是不太礼貌的。”

我：“哦同学你放心，我发誓我对 cos 柯希莫的人没有任何意见。”

（注释：柯希莫是卡尔维诺所著《树上的男爵》主人公，他在跟家里人大吵一架后，愤然爬上了一棵树，发誓这辈子再也不回到地面，结果他真的在树上过完了一生。）

ㄚ：“随意揣测意图也是不太礼貌的。但是，如果你能够坐下来陪我聊聊天，我倒是可以告诉你。很久没有人找过我聊天了。”

我：“非常感谢。聊天是我们很擅长的事情。”

于是我和 X 一左一右坐在了 ㄚ 旁边。

ㄚ：“该怎么说起呢？”

ㄚ：“我一直觉得，只有从我现在这个视角看过去，世界才是合理的模样。这样对我而言才算‘正’。”

X：“嗯。”

我：“这个表述很有趣。”

ㄚ：“所以，我只是尝试回归了我本该拥有的视角。”

ㄚ：“实话说，我之前一直觉得这个世界的视角很奇怪，虽然我不知道你们怎么想，但我真的感觉很别扭。”

X：“……这样不累吗？”

ㄚ：“累，当然累。我的腿已经酸痛得不行了。但是，还是想倒吊得再久一点。”

X：“是因为有了重力，我们才拥有了这个所谓的‘正’视角。”

ㄚ：“是的，看来你能理解我的感受。”

我：“诶诶？这么快就理解了吗？”

ㄚ：“重力真是一个很可恶的东西，我从一开始就没想着需要重力，但它还是把我拽向地面。”

X：“重力就是牢笼。”

ㄚ：“嗯，我们本来可以飞上天空的。”

我们本来可以飞上天空的——X 在后来对这句话若有所思。我果然还是觉得 ㄚ 在 cos 柯希莫，绝对没错，但 X 不这么认为。

自那之后，仍然经常看见 ㄚ 倒吊在树上，还经常换着树吊。我想过把 ㄚ 吊过的树都做个记录，观察一下特征与分布范围，但由于高三学业繁重，遂放弃。

我：“还好是倒吊在树上，如果是正着吊的就大事不好了。”

X：“你很有幽默感嘛。”

叙述到这里本来可以结束了，ㄚ 会日复一日地倒吊在树上，成为校园里的景观。然后我们会成人，高考，毕业，走向新的生活，成为在预定轨道上终年迁徙着的雁群之一。

但是不巧的事情还是发生了。

ㄚ 失踪了，就在我看见 X 与其长谈的那个下午之后。

自从第一次遇到 ㄚ 起，X 好像就有什么地方变了，最显著的变化，是越来越少与我在应元楼旁的树下聊天了。这其实不是什么值得难过的事，我早已习惯了阶段性的陪伴，人与人之间说不清道不明的东西有很多。

但是 ㄚ 失踪了。这就不太寻常了，其实倒吊在树上已经足够不寻常了不是吗？就算失踪了或许也没什么好惊讶的。也许是德育处的老师们逼着 ㄚ 下树，此时飘来一个热气球，ㄚ 就抓起它垂下的绳子飞向天空了。

缺少了 ㄚ 的校园变得有些无聊，不过我和 X 又经常坐在树下聊天了。

X：“你从来没有想倒吊在树上的欲望吗？”

我：“啊？”

X：“嗯这是一个……普通的一般疑问句。没什么，就是随便问问。”

这段对话的第二天，我看见了 X 倒吊在树上。

这次走路的距离就让氛围更加尴尬了，不如说我是在长距离的面面相觑之中，才终于挪到了那棵树下。

我：“这个视角的我，是什么样的呢？”

X：“没什么不一样，或许更加好看了。”

我：“这话是礼貌性的吧。”

X：“指出这句话是礼貌性的可就不太礼貌了。”

我：“你跟 ㄚ 学到了真东西。”

从这之后，校园里的景观换成了 X。我多少有点百感交集。

倒吊着的视角是什么样的？对于这个问题我仍然觉得没有思考的必要。第一是这或许很容易想象，第二是我不能从结论中获得结论以外的任何东西。

况且，我仍然能继续跟 X 聊天。这个很重要。

我：“你也会飞向天空吗？”

X：“……”

我：“一个普通的一般疑问句而已。”

X：“如果我说我会呢？”

我没有回答。

高三渐渐步入后期，于是我开始重新思考一切。与 X 在树下聊天的时间，无论如何都越来越少了。

同时，我也一直在各处打听 ㄚ 的下落。奇怪的是，很多人都对“一个喜欢倒吊在树上的人”有印象，但谁也不知道 ㄚ 在哪个班，有什么朋友，是个怎样的人。其实我也不太知道。

我：“那你知道吗？”

X：“什么？”

我：“我是说，你的前辈 ㄚ。”

X：“对于 ㄚ，我只有深深的感谢。”

X 一边说着，一边晃了一晃垂落的头发。

现在想来，X 并没有回答我的问题，但我也没追问下去。再过不久就是一模、二模，然后身边只剩下面临高考的紧张气氛了。我和 X 也不知道从什么时候起，就不约而同地再也没有一起聊过天。

X 在高考前一天，在树上倒吊了一整个下午。我没有走近。

ㄚ 仍处于失踪状态。这件事似乎只有我在乎了。

什么都没有发生，时间就这样过去了。

每周都会迎来放学的日子，但高考很可能只有一次。可是我现在觉得，高考也挺无聊的。

毕业之后，我也没有再跟 X 见过面。偶尔向老同学问起 X 的去处，也没有答案。其实这跟 ㄚ 的失踪并无差别，只是没那么突然罢了。

到最后，我也不知道 X 和 ㄚ 为什么会想要倒吊在树上。

不过，自那之后，我看到路边每棵树时的心情就发生了一丝变化。我似乎隐隐地期盼着看到一个倒吊在树上的身影。

最近从校友群里听说，学校大改造升级，中心广场的树坛都被拆了。于是那里已经不再有树了。
